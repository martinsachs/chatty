# Sicherheit

## Lücke melden

Bitte **nicht** als öffentliches Issue. Stattdessen privat über GitHub:
**Security → Report a vulnerability** (<https://github.com/martinsachs/chatty/security/advisories/new>).

Hilfreich sind: betroffene Version bzw. Commit, Variante (Tauri oder native), Schritte zum Nachstellen,
erwartete Wirkung. Patches sind willkommen.

## Unterstützte Versionen

Nur die jeweils neueste Version erhält Fixes. Installationen aktualisieren sich selbst (signierte Updates).

## Ablauf

Eingangsbestätigung in der Regel innerhalb weniger Tage. Nach dem Fix erscheint eine neue Version, auf Wunsch
mit Nennung der meldenden Person. chatty ist ein Freizeitprojekt ohne Gewährleistung (siehe README).
